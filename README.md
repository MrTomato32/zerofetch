# zerofetch
![Release](https://img.shields.io/github/v/release/MrTomato32/zerofetch) ![Stars](https://img.shields.io/github/stars/MrTomato32/zerofetch?style=flat) ![Last commit](https://img.shields.io/github/last-commit/MrTomato32/zerofetch) ![Commit activity](https://img.shields.io/github/commit-activity/m/MrTomato32/zerofetch) ![Code size](https://img.shields.io/github/languages/code-size/MrTomato32/zerofetch) ![Issues](https://img.shields.io/github/issues/MrTomato32/zerofetch) ![Platform](https://img.shields.io/badge/platform-linux-informational?logo=linux&logoColor=white) ![Made with C](https://img.shields.io/badge/made%20with-C-blue?logo=c)

A simple neofetch-like tool that prioritizes speed and efficiency over aestethics.

zerofetch displays useful information about your system, including:
- OS and kernel version
- CPU model
- Memory usage
- Disk usage
- GPU model
- Uptime
- Shell and terminal details

## Installation

bash
git clone https://github.com/<your-username>/zerofetch.git
cd zerofetch
